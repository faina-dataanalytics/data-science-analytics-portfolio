# Data Science & Analytics Portfolio

Dieses Repository präsentiert ausgewählte Analyseprojekte aus den Bereichen **SQL**, **Python**, **Statistik**, **Machine Learning**, **Tableau**, **Power BI** und **Product Analytics**.
